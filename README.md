# GoIT Data Engineering · ДЗ 03

Скрипт читає три CSV, видаляє рядки з пропусками, обчислює витрати за категоріями та знаходить топ-3 категорії для вікової групи 18–25 років включно.

Завантажте `users.csv`, `purchases.csv` і `products.csv` з матеріалів курсу
в папку `data/` поряд із `ht03_oya.py`.

Запуск у середовищі з PySpark 4.2.1 та Java 17.

```bash
python ht03_oya.py
```

Для іншого розташування файлів використайте `--data-dir /шлях/до/csv`.

Сума позиції дорівнює `quantity × price`. Пункт 3 враховує очищені покупки з відомим товаром. У пунктах 4–6 додатково приєднуємо очищених користувачів і застосовуємо віковий фільтр. Відсоток категорії обчислюємо від усіх витрат цієї вікової групи. Під час виведення округлюємо його до двох знаків.

Скриншоти в папці `screenshots/` показують вивід `df.show()` для пунктів 1–6.
